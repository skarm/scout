# Пример использования Go API

[English](README.md) · Русский

[main.go](main.go) показывает проверку локального навыка или плагина, применение
политики и вывод JSON-отчёта через публичные пакеты `scout`, `policy` и `report`.
В примере отчёт идёт в stdout, диагностика — в stderr. Загрузки, сетевой поиск
уязвимостей и передача исходников отключены.

Выполняйте команды из корня репозитория. Замените `./my-skill` существующим
локальным путём.

## Полная сборка

Используйте ту же обёртку нативных зависимостей, что и для CLI Scout:

```sh
go run -mod=readonly ./internal/dev/builddeps -- \
  go build -mod=readonly -tags=static_link -o /tmp/scout-go-api ./examples/go-api
/tmp/scout-go-api ./my-skill
```

В примере выбраны `scout.DefaultOptions()` и профиль `standard`.
Требования описаны в [руководстве сборки](../../docs/development/native-build.ru.md).

## Core-сборка

Соберите пример без дополнительных нативных движков и явно выберите
сокращённый набор проверок флагом `-core`:

```sh
go build -mod=readonly -tags=coreonly -o /tmp/scout-go-api-core ./examples/go-api
/tmp/scout-go-api-core -core ./my-skill
```

`-core` выбирает `custom` со встроенными проверками и адаптированными паттернами.
Без этого флага core-бинарник завершится ошибкой создания Scanner: профиль
по умолчанию требует недоступные движки. Сокращённый набор работает и в полной сборке.

## Результат и код завершения

Политика блокирует начиная с `high` и использует консервативную область проверки.
Ограничения анализа могут требовать ручной проверки даже без находок.

- `0`: проверка завершена, политика разрешает допуск.
- `1`: проверка завершена, политика требует ручной проверки или блокирует допуск.
- `2`: неверные аргументы, ошибка создания Scanner или сканирования,
  неполная проверка либо ошибка вывода.

В примере Ctrl+C отменяет контекст, а Scanner закрывается перед выходом.
Если сканирование вернуло ошибку вместе с доступным Run с дайджестом,
эти данные всё равно оцениваются и выводятся перед завершением с кодом `2`.
Ошибка до создания Run даёт только диагностику. Учитывайте код завершения вместе
с JSON-отчётом: пустой список находок сам по себе не означает разрешение.

Параллелизм, владение ресурсами, лимиты и проверка отчёта описаны
в [контрактах Go API](../../docs/development/go-api.ru.md).
