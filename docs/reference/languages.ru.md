# Языки и форматы конфигурации

[English](languages.md) · Русский

Scout анализирует захваченный код, блоки Markdown и поддерживаемые вложения,
не запуская проверяемые программы. Доступные движки показывает `scout capabilities`.

## Go

`go/parser` строит AST без импорта проверяемых пакетов. GO001–GO006 проверяют
построение shell-команд, чувствительные файлы, выбранные потоки credentials в HTTP,
динамический SQL и отключённую проверку TLS. Учитываются aliases и локальное
затенение; общего разрешения типов и полного графа вызовов нет.

## Python

Полная сборка использует Tree-sitter и ограниченную CST→IR проекцию без Python
runtime. Проверки охватывают выбранные process/eval/import operations,
чувствительные файлы, сетевые аргументы, deserialization, reconstruction и локальные потоки.
Неподдержанные конструкции и неразрешимые потоки остаются пробелами проверки.

## Shell

Ограниченные деревья команд охватывают pipelines, assignments, redirects
и substitutions. `mvdan.cc/sh/v3/syntax` отдельно разбирает декларации команд
и источников. SH001–SH004 проверяют download→execute, credentials в запросах,
eval/source/shell capabilities и чувствительное чтение. Учитываются выбранные
curl/wget options и происхождение сохранённых файлов. Динамические аргументы
и неподдержанный control flow ограничивают полноту.

## JavaScript и TypeScript

Полная CGO-сборка использует официальные Tree-sitter grammars. JS001–JS006 проверяют
shell APIs, dynamic evaluation, credentials в сетевых аргументах, динамический SQL,
чувствительные файлы и отключённую проверку TLS. Учитываются выбранные ESM/CommonJS
aliases, destructuring, затенение, перезаписи и ветвления.
Неподдержанный control flow оставляет пробелы; core/no-CGO сообщает недоступность грамматик.

## SQL

Go-парсер работает в core-сборке. SQL001–SQL004 проверяют выбранные разрушительные
операции, изменения полномочий/RLS, серверный ввод-вывод файлов и программ,
отключение лимитов. Комментарии, строки и идентификаторы различаются.
Dollar-quoted procedural bodies не поддержаны. SQL-интерполяция Go и JS/TS
проверяется на AST соответствующего языка.

## Конфигурации

JSON проверяет повторяющиеся decoded keys. YAML и TOML требуют движков полной
сборки. YAML aliases, merge и custom tags не поддержаны; TOML spans консервативны.
Успешный разбор не доказывает совместимость со всеми host loaders.

## Область проверки

Межфайловые потоки используют выбранные captured imports и функции:
[проверки потоков](hardening-2026-10-29.ru.md#потоки-данных).
Ошибки разбора, неподдержанные формы и исчерпанные лимиты остаются видимыми пробелами.
`complete` относится к выбранным проверкам; [область policy](../user/inspection-profiles.ru.md#область-проверки)
определяет отношение к заявленным языковым ограничениям.
