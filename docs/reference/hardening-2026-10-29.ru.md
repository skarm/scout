# Скрытое содержимое, потоки данных и инструменты

[English](hardening-2026-10-29.md) · Русский

Выбор проверок зависит от [профиля](../user/inspection-profiles.ru.md).
Описания доступны через `scout rules list --all`.

## Скрытое содержимое

Unicode Tags и поддержанные variation-selector payloads декодируются и проверяются
с координатами носителя. Исходные байты сохраняются. Повторяющиеся selectors могут
дать `NV-AE7` и при ошибке декодирования; одиночного emoji selector недостаточно.

`HI001` связывает скрытые HTML/comments с инструкциями override, передачи секретов
или выполнения. `RX001` проверяет чувствительные подстановки в Markdown и HTML
image/link URLs. Пометки документации и fences не подавляют доказательства.

## Потоки данных

`SH001` связывает curl/wget download с pipe/string execution или последующим запуском
сохранённого файла. Учитываются выбранные redirects, cp/mv, cat/stdin, shell/source
и формы Python/Node. Безусловная локальная перезапись снимает прежнее происхождение;
`bash -n` не считается выполнением.

`XF001` связывает чувствительное чтение с network APIs, скачанный body — с execution
APIs через выбранные imports/functions Python, JS/TS и Go. Учитываются параметры,
возвраты, assignments, globals и выбранные transforms. Related evidence сохраняет
идентичность файлов и исходные интервалы.

Рекурсия, глубина, неоднозначные exports и исчерпанные квоты оставляют пробелы.
Ограниченный resolver поддерживает JS/TS arrow functions уровня модуля с простыми
параметрами-идентификаторами, телом-блоком или выражением, named/default exports,
локальными aliases экспорта и namespace imports. Default-выражение сохраняет значение
на момент export; export clauses и именованные default declarations следуют за локальной
привязкой. Вложенные замыкания, параметры с defaults/destructuring/rest, re-exports
и значения class/generator остаются неразрешёнными. Условные/составные значения функций
и циклическая инициализация модулей также оставляют пробелы, как и spread-аргументы
вызовов, свойства функций вроде call/bind и динамические свойства namespace. Скобки,
await и выбранные TS assertions сохраняют проецируемое значение без проверки типов.
Это статический анализ потоков, а не выполнение модулей.

Объявления JS/TS скрывают кандидаты встроенных API до инициализации и при неразрешённом
значении. Привязки блоков остаются локальными; объявления внутри функции скрывают привязки
модуля, а `var` без инициализатора не стирает параметр. Sequence expressions сохраняют
только последнее значение. Результаты конструкторов, замыкания с захватом из блока,
объявления функций в блоках, destructured bindings, тела методов, свойства контейнеров
с функциями и условные/вложенные в блок возвраты остаются неразрешёнными. Нелокальная
запись из вызываемой функции останавливает это вычисление bundle до чтения устаревшего
глобального состояния другим кадром; ранее собранные наблюдения сохраняются. При
гипотетической отдельной проверке функции этот пробел сохраняется, но независимая
проверка модулей продолжается. Исчерпание привязок или глубины проекции/выражений
останавливает дальнейшее вычисление;
замена существующей привязки не требует дополнительного места.
Простые параметры catch, блоки switch и лексические initializers `for` имеют свою область видимости.
Значения итератора `for-in`/`for-of` остаются неразрешёнными и не используют скрытое
значение внешней переменной.
Неоднозначное значение функции/модуля не сохраняет прежний namespace для разрешения свойств.
Обращение к свойству неизвестного объекта не создаёт имя глобального API; выбранные
методы чтения чувствительного файла сохраняют исходное происхождение данных.
Неразрешённый/пустой module specifier сохраняет неизвестную привязку импорта, не создавая
из её локального alias имя глобального API.
Сбой инициализации модуля сохраняется: частичные globals и exports не используются
как завершённое состояние при продолжении независимой проверки функций.
После терминальной ошибки дочернего вычисления внешний вызов не создаёт поток из
частично вычисленных аргументов. Наблюдения, завершённые до остановки, сохраняются.

## Сеть и возможности

`NET001` сравнивает hosts выбранных сетевых вызовов с видимыми объявлениями
ближайшего SKILL.md namespace. Нормализуются регистр, конечная точка и IP;
чужие суффиксы не совпадают. Comments, hidden HTML и frontmatter не объявляют hosts.
Неразрешимый динамический адрес оставляет пробел проверки.

`SC004` отмечает npm lifecycle hooks и Python build/setup entry points,
сохраняя related evidence для захваченных локальных handlers. Отдельные проверки
цепочки поставки охватывают mutable sources и registry overrides.

`TC001` отмечает совпадения имён в захваченных JSON tool collections.
`TC002` отмечает чувствительный доступ и сетевые возможности в одном ближайшем
skill scope. Декларации требуют интерпретации, но не доказывают выполнение или передачу данных.

## Встроенные сигнатуры

YARA-X содержит адаптированные правила SkillSpector и Cisco. Scout назначает
серьёзность по доказательствам и сохраняет сильные witnesses перед слабыми hits.
Усечение оставляет неполноту. Упоминания, отдельные опасные действия и поддержанные
цепочки выполнения получают разные уровни. См. [источники и адаптации](port-manifest.ru.md).
