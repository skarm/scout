# Скрытое содержимое, потоки данных и инструменты

[English](hardening-2026-10-29.md)

Команда `scout rules list --all` показывает описания правил. Набор проверок задаёт [профиль](../user/inspection-profiles.ru.md).

## Скрытое содержимое

Scout декодирует поддерживаемые последовательности Unicode Tags и вариационных селекторов, сохраняя смещения в исходных байтах. Повторяющиеся селекторы могут вызвать `NV-AE7` даже при сбое декодирования. Одного селектора эмодзи недостаточно.

`HI001` ищет в скрытом HTML и комментариях инструкции по переопределению правил, передаче секретов или выполнению команд. `RX001` проверяет подстановки чувствительных данных в URL ссылок и изображений Markdown и HTML. Метки и блоки кода дают контекст без подавления находок.

## Потоки данных

- `SH001` связывает отдельные загрузки через curl и wget с выполнением через конвейер, строку команды или сохранённый файл. Проверка учитывает поддерживаемые копирования, перемещения и перенаправления. Известная локальная перезапись сбрасывает связь с загрузкой.
- `XF001` связывает чтение чувствительных данных с сетевыми API, а загруженное содержимое с API выполнения. Проверка отслеживает часть импортов, функций и преобразований строк в захваченном коде Python, JavaScript, TypeScript и Go.
- `DNS001` связывает чувствительные значения с именами DNS-запросов в этих языках и отдельных командах Shell. Проверка учитывает известные аргументы стандартных резолверов, отдельные экземпляры резолверов и ограниченные одиночные запросы через `dig`, `host` и `nslookup`. Межфайловые потоки сохраняют доказательства `XF001`.

Поддерживаемые литералы токенов определяются по правилам `SE002`–`SE007` и сохраняют исходные диапазоны при присваиваниях и отдельных преобразованиях. Scout исключает значение литерала из текста находки и не проверяет токен у провайдера.

У каждого блока Markdown собственные привязки имён. Явный локальный импорт может ссылаться на захваченный модуль в той же области. Находки сохраняют файлы, хеши и исходные диапазоны. Рекурсия, неразрешённые импорты или вызовы, условные результаты и исчерпание лимитов могут оставить пробелы в анализе. Динамическое DNS-имя может оставить пробел даже при найденном потоке. Scout не запускает проверяемый код и не отправляет DNS-запросы от его имени.

## Сеть и возможности

- `NET001` сравнивает отдельные HTTP-хосты и литеральные DNS-имена с видимыми декларациями ближайшего `SKILL.md`. Проверка нормализует регистр, завершающие точки и IP-адреса. Комментарии, скрытый HTML и метаданные frontmatter не задают хосты.
- `SC004` отмечает lifecycle hooks npm и точки входа сборки или установки Python. Если локальный обработчик найден, отчёт ссылается на его захваченный исходник.
- `TC001` отмечает совпадения идентификаторов в захваченных JSON-коллекциях инструментов. `TC002` отмечает сочетания доступа к чувствительным данным и сетевых возможностей в области одного навыка. Одни декларации не подтверждают выполнение или передачу.

## Встроенные сигнатуры

Scout определяет серьёзность находок YARA-X по сохранённым доказательствам и отдаёт приоритет более сильным. Усечение анализа оставляет пробел в охвате. [Источники и лицензии адаптаций](port-manifest.ru.md)
