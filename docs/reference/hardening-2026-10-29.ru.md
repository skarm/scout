# Скрытое содержимое, потоки данных и инструменты

[English](hardening-2026-10-29.md) · Русский

Выбор проверок зависит от [профиля](../user/inspection-profiles.ru.md).
Описания доступны через `scout rules list --all`.

## Скрытое содержимое

Unicode Tags и поддержанные variation-selector payloads декодируются и проверяются
с координатами носителя. Исходные байты сохраняются. Повторяющиеся selectors могут
дать `NV-AE7` и при ошибке декодирования; одиночного emoji selector недостаточно.

`HI001` связывает скрытые HTML/comments с инструкциями override, передачи секретов
или выполнения. `RX001` проверяет чувствительные подстановки в Markdown и HTML
image/link URLs. Пометки документации и fences не подавляют доказательства.

## Потоки данных

`SH001` связывает curl/wget download с pipe/string execution или последующим запуском
сохранённого файла. Учитываются выбранные redirects, cp/mv, cat/stdin, shell/source
и формы Python/Node. Безусловная локальная перезапись снимает прежнее происхождение;
`bash -n` не считается выполнением.

`XF001` связывает чувствительное чтение с network APIs, скачанный body — с execution
APIs через выбранные imports/functions Python, JS/TS и Go. Учитываются параметры,
возвраты, assignments, globals и выбранные transforms. Related evidence сохраняет
идентичность файлов и исходные интервалы.

Рекурсия, глубина, неоднозначные exports и исчерпанные квоты оставляют пробелы.
Ограниченный resolver не разрешает ES arrow/default exports для XF001.

## Сеть и возможности

`NET001` сравнивает hosts выбранных сетевых вызовов с видимыми объявлениями
ближайшего SKILL.md namespace. Нормализуются регистр, конечная точка и IP;
чужие суффиксы не совпадают. Comments, hidden HTML и frontmatter не объявляют hosts.
Неразрешимый динамический адрес оставляет пробел проверки.

`SC004` отмечает npm lifecycle hooks и Python build/setup entry points,
сохраняя related evidence для захваченных локальных handlers. Отдельные проверки
цепочки поставки охватывают mutable sources и registry overrides.

`TC001` отмечает совпадения имён в захваченных JSON tool collections.
`TC002` отмечает чувствительный доступ и сетевые возможности в одном ближайшем
skill scope. Декларации требуют интерпретации, но не доказывают выполнение или передачу данных.

## Встроенные сигнатуры

YARA-X содержит адаптированные правила SkillSpector и Cisco. Scout назначает
серьёзность по доказательствам и сохраняет сильные witnesses перед слабыми hits.
Усечение оставляет неполноту. Упоминания, отдельные опасные действия и поддержанные
цепочки выполнения получают разные уровни. См. [источники и адаптации](port-manifest.ru.md).
