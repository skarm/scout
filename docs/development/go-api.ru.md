## Создание и закрытие Scanner

Начинайте со `scout.DefaultOptions()`; нулевые options недопустимы.
Standard и Review требуют nil `Checks`, Custom — явное значение.
Недоступность выбранного движка вызывает ошибку конструктора.

```go
options := scout.DefaultOptions()
scanner, err := scout.New(ctx, options)
if err != nil {
    return err
}
defer scanner.Close()
```

Scanner поддерживает параллельные сканирования; копировать его нельзя.
`Close` запрещает новую работу, ожидает активные вызовы и освобождает нативные
ресурсы. Повторный вызов и nil допустимы, но активная работа не отменяется.
При необходимости отмените контексты сканирований. Пользовательский review provider
должен поддерживать параллельные вызовы и соблюдать отмену.

## Входы и неполные результаты

`Path` выбирает локальный вход. `Remote` проверяет адрес без загрузки; сканирование
также требует включённых download options. `Compare` заново проверяет два локальных
пути. `ScanMany` сохраняет порядок входов и использует общие лимиты.

`Reader` и `ReaderContext` заимствуют одноразовые потоки без закрытия.
`ReadContext` должен быстро завершаться при отмене. Обычный `Read` должен
завершаться самостоятельно: адаптер не может прервать его.

Ошибка предварительной проверки может возникнуть до создания Run.
При `ErrIncomplete` сохраняйте доступный Run и доказательства.
Проверяйте вложенные сигнальные ошибки через `errors.Is`.

## Оценка и вывод

Run хранит наблюдения. `policy.New` копирует доверенные настройки и исключения;
`Gate.Evaluate(run, now)` применяет их в явно заданный момент времени.
`report.NewDocument` объединяет значения без проверки. `report.Prepare` проверяет
привязку и сохраняет независимый снимок для многократного вывода.

```go
document := report.NewDocument(run, gate.Evaluate(run, time.Now().UTC()))
prepared, err := report.Prepare(document)
if err != nil {
    return err
}
if err := prepared.Write(output, report.JSON); err != nil {
    return err
}
```

Пример предполагает готовые Run, Gate и writer. Ошибки сканирования и записи
обрабатывайте отдельно от `policy.PreparedCode(prepared)`. `Snapshot` возвращает независимую копию;
вывод не закрывает writer.

## Координаты, лимиты и доверие

Байтовые интервалы начинаются с нуля и не включают правую границу.
Текстовые координаты начинаются с единицы и считают кодовые точки Unicode.
Бинарные строки и столбцы равны нулю. Смещения дочернего объекта относятся
к его байтам; `ParentRange` охватывает представление без точной побайтовой карты
после распаковки или декодирования.

Лимиты захвата и извлечения действуют на вход. Общие лимиты и сохраняемые находки
действуют на весь запуск. Нативные лимиты и отмена кооперативные.
Загрузка, сетевой поиск уязвимостей и передача исходников имеют отдельные разрешения.

MCP заимствует Scanner и Gate. Его `Serve` владеет входным `io.ReadCloser`
и закрывает его при отмене; такой reader должен разблокироваться после закрытия.
